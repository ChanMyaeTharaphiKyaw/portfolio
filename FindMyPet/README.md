FindMyPet - Lost and Found Pet Information System

Programming Languages

* HTML5
* CSS3
* JavaScript

Framework and Libraries

* Tailwind CSS
* PHPMailer
* Dompdf
* GD Library

Database

* MySQL

Web Server

* Apache from Xampp



Requirements

Before running the system, Xampp, PHP, PHPMailer, Dompdf, GD Library, MySQL and WebSocket must be installed.


Installation Guide

Step 1 - Install Xampp

Step 2 - Create a folder in xampp/htdocs and copy project's source code into it.

Step 3 - Start Apache and MySQL in Xxampp

Step 4 - Create a new database in phpMyAdmin and import provided SQL file.

Step 5 - Update database connection in pdo file from project's source code.

Step 6 - Open browser and run the system.

Step 7 - Open terminal, navigate to WebSocket directory, start and run WebSocket server while using system.
